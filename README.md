# MathLearningNotes

Personal study diary of mathematics learning notes, mostly in Jupyter Notebook format with LaTeX equations. Notes are organised by subject in the top-level directories: `algebra/`, `calculus/`, `discrete-mathematics/`, `fractals/`, and `trigonometry/`.

Most notes are **Jupyter Notebook (.ipynb)** files, which render natively on GitHub with MathJax support for LaTeX. A few notes are Markdown (`.md`), and some notebooks are accompanied by image files (`.png`, `.jpg`).

## Working with the notes

To open the notebooks locally, install Jupyter (these notes use numpy, matplotlib, sympy, and ipywidgets):

```bash
pip install jupyter numpy matplotlib sympy ipywidgets
jupyter notebook
```
